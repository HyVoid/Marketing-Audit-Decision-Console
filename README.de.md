# Marketing-ROI gegen CRM-Realität prüfen statt gegen Plattformbehauptungen

![License](https://img.shields.io/badge/License-Apache%202.0-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Browser%20%2B%20Excel-green.svg)
![Tool](https://img.shields.io/badge/Tool-Marketing%20Decision%20Support-orange.svg)

**Ein kostenloses browser- und Excel-basiertes Marketing-Audit-Framework, das Google Ads-, GA4-, Search Console- und CRM-Umsatzdaten abgleicht, um tatsächliche Akquiseleistung, versteckte Attributionsinflation und verschwendete Werbeausgaben aufzudecken.**

**Keine Anmeldung. Keine Installation. Kostenlos in Ihrem Browser.**

Probieren Sie die Browser-Version kostenlos aus. Wenn Sie die Excel-Version benötigen, können Sie sie mit einer 30-tägigen Geld-zurück-Garantie ohne Fragen erwerben.

## Was es beim Verfolgen hilft

* Gemeldete Werbe-Conversions gegenüber CRM-bestätigten Geschäftsergebnissen.
* Tatsächliche Kundenakquisekosten nach Entfernung ungültiger und nicht qualifizierter Leads.
* Von der Kampagne generierter Umsatz basierend auf Finanzaufzeichnungen statt Werbeplattform-Behauptungen.
* Versteckte Attributionslecks zwischen Marketingplattformen und betrieblicher Realität.
* Suchbegriffe, die Budget verbrauchen, ohne qualifizierte Chancen zu generieren.
* Die fünf wirkungsvollsten Optimierungsmaßnahmen, sortiert nach rückgewinnbarem Wert.

---

## Warum ich dies gebaut habe

Ich baute dieses Framework ursprünglich, nachdem ich wiederholt denselben analytischen Fehler in lokalen Dienstleistungsunternehmen, Agenturen und kleinen Marketingteams erlebt hatte: jeder optimierte Marketingkampagnen mit Zahlen, die technisch korrekt, aber betrieblich falsch waren.

Eine Kampagne könnte innerhalb von Google Ads erfolgreich erscheinen:

| Kennzahl      | Plattformbericht |
| ----------- | --------------- |
| Ausgaben       | $15,843         |
| Conversions | 480             |
| CPA         | $33             |

Der Unternehmer würde schließen:

> "Unser Marketing funktioniert."

Nach dem Abgleich derselben Kampagnen mit CRM-Datensätzen und abgeschlossenen Aufträgen sah das tatsächliche Geschäftsergebnis jedoch ganz anders aus:

| Kennzahl          | CRM-geprüfte Realität |
| --------------- | ------------------- |
| Qualifizierte Leads | 95                  |
| Abgeschlossene Aufträge  | 24                  |
| Echte CPA        | $166                |
| Echter ROAS       | 3,05×               |

Das Problem war nicht ungenaue Software.

Das Problem war ein analytisches Versagen: Marketingplattformen optimieren für aufgezeichnete Ereignisse, während Unternehmen von abgeschlossenen Transaktionen und eingezogenem Umsatz überleben.

Dieses Projekt produktisiert ein wiederholbares Argumentations-Framework:

1. Beginnen Sie mit der behaupteten Marketingleistung.
2. Verfolgen Sie jede Conversion in die Betriebssysteme.
3. Entfernen Sie disqualifizierte, duplizierte und nicht-kommerzielle Ereignisse.
4. Berechnen Sie die Akquiseökonomie mit der Geschäftsrealität neu.
5. Priorisieren Sie Interventionen nach finanziellem Einfluss.

Statt ein weiteres Dashboard zu bauen, baute ich eine wiederverwendbare Audit-Methodik, die eine einfachere Frage beantwortet:

> **„Welche Marketing-Dollars haben tatsächlich Umsatz erzeugt?"**

## Für wen dies ist

Dieses Tool ist konzipiert für:

* Lokale Dienstleistungsunternehmen, die Google Ads schalten.
* Kleine und mittlere Agenturen, die Marketing-Audits durchführen.
* Marketing-Operations-Teams, die Attributionsqualität validieren.
* Unternehmer, die Marketingausgaben mit tatsächlichem Umsatz abgleichen wollen.
* Berater, die Akquiseeffizienz-Reviews durchführen.

Dieses Tool ist nicht konzipiert für:

* Enterprise-Marketing-Automatisierungsplattformen.
* Multi-Touch-Attributionsmodellierungssysteme.
* Kundendatenplattformen (CDP).
* Organisationen, die Echtzeit-Streaming-Analysen benötigen.

**Keine Spreadsheet-Expertise erforderlich. Öffnen Sie die Browser-Version oder das Excel-Workbook und beginnen Sie sofort mit dem Audit.**

### Drei Fallen, die selbst erfahrene Marketingteams fangen

#### Falle #1 — Plattform-Conversion-Inflation

**Getroffene Entscheidung:**

Budget erhöhen, weil CPA niedrig erscheint.

| Kennzahl      | Plattform | Geprüft |
| ----------- | -------- | ------- |
| Ausgaben       | $15,843  | $15,843 |
| Conversions | 480      | 95      |
| CPA         | $33      | $166    |

**Warum diese Argumentation scheitert:**

Werbeplattformen optimieren für aufgezeichnete Ereignisse statt für Geschäftsergebnisse.

**Richtiger Ansatz:**

Akquiseökonomie erst nach CRM-Abstimmung berechnen.

**Richtiges Entscheidungsergebnis:**

Budgetallokation reduzieren und Conversion-Tracking neugestalten.

<details>
<summary>Formellogik</summary>

```excel
=IFERROR((Reported_Conversions-Real_Leads)
/Reported_Conversions,0)
```

```excel
=IFERROR(Total_Spend/Matched_Real_Leads,0)
```

</details>

---

#### Falle #2 — Optimierung von hochvolumigen Keywords mit niedriger Qualität

**Getroffene Entscheidung:**

Gebote auf hochvolumige Suchbegriffe erhöhen.

| Suchbegriff          | Ausgaben | Leads | Entscheidung |
| -------------------- | ----- | ----- | -------- |
| emergency plumber    | $220  | 12    | Behalten     |
| free plumbing advice | $310  | 0     | Ausschließen  |

**Warum diese Argumentation scheitert:**

Klickvolumen misst Aufmerksamkeit, keine kommerzielle Absicht.

**Richtiger Ansatz:**

Suchbegriffe anhand qualifizierter Lead-Produktion bewerten.

**Richtiges Entscheidungsergebnis:**

Nicht-kommerzielle Suchmuster ausschließen.

<details>
<summary>Formellogik</summary>

```excel
=IF(
 AND(
   Spend>(Max_CPA*1.5),
   Leads=0
 ),
 "CRITICAL WASTE",
 "KEEP"
)
```

</details>

---

#### Falle #3 — Budgetallokation basierend auf gemeldetem ROAS

**Getroffene Entscheidung:**

Budget zu scheinbar erfolgreichen Kampagnen verschieben.

| Kampagne   | Gemeldeter ROAS | Echter ROAS |
| ---------- | ------------- | --------- |
| Campaign A | 7,8×          | 1,4×      |
| Campaign B | 3,2×          | 4,5×      |

**Warum diese Argumentation scheitert:**

Umsatzattribution bricht zusammen, wenn betriebliche Bestätigung fehlt.

**Richtiger Ansatz:**

ROAS aus Finanzaufzeichnungen berechnen.

**Richtiges Entscheidungsergebnis:**

Ausgaben zu Kampagnen mit verifizierter Umsatzproduktion neu allokieren.

<details>
<summary>Formellogik</summary>

```excel
=IFERROR(
 Real_Revenue
 /
 Total_Spend,
0)
```

</details>

### Beispielszenario

Ein Wohn-HVAC-Unternehmen gibt monatlich \$18.400 für acht Google-Ads-Kampagnen aus.

Die erste Berichterstattung zeigt:

| Kennzahl               | Wert   |
| -------------------- | ------- |
| Werbeausgaben             | $18,400 |
| Gemeldete Conversions | 562     |
| Gemeldete CPA         | $32,74  |

Nach dem Import der CRM-Daten:

| Kennzahl          | Wert   |
| --------------- | ------- |
| Qualifizierte Leads | 118     |
| Gebuchte Aufträge     | 31      |
| Umsatz         | $57,200 |
| Echte CPA        | $155,93 |
| Echter ROAS       | 3,11×   |

Weitere Analyse zeigt:

* 67 % der gemeldeten Conversions gelangten nie ins CRM.
* Drei Kampagnen generierten 72 % des tatsächlichen Umsatzes.
* Zweiundzwanzig Suchbegriffe verbrauchten \$3.480 bei null gebuchten Aufträgen.
* Eine Keyword-Gruppe „free HVAC training" verbrauchte allein \$940.

Empfohlene Maßnahmen:

1. Zwei leistungsschwache Kampagnen pausieren.
2. Achtzehn negative Keywords hinzufügen.
3. 35 % des Budgets zu verifizierten Kampagnen neu allokieren.
4. Front-End-Conversion-Tracking durch CRM-Validierung ersetzen.

Erwartete jährliche Einsparungen:

```
Recovered Waste:
$3,480/month × 12
=
$41,760/year
```

### Validierungsregeln

| Feld           | Regel             | Fehlerverhalten          |
| --------------- | ---------------- | ----------------------- |
| Audit-Zeitraum    | Muss 30/60/90 sein | Eingabe ablehnen            |
| Kampagnen-ID     | Darf nicht leer sein  | Datensatz ausschließen          |
| Lead-ID         | Muss eindeutig sein   | Duplikat markieren          |
| Umsatz         | Muss ≥0 sein       | Validierungsfehler zurückgeben |
| Gebuchter Auftrag      | Nur 0 oder 1      | Wert ablehnen            |
| Qualitätsscore   | Ganzzahl 1–10     | Anomalie markieren            |
| Attributionslücke | >50 %             | Alarm generieren          |
| Verschwendungsschwelle | Konfigurierbar     | Empfehlung auslösen  |

</details>

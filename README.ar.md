**إطار تدقيق تسويقي مجاني يعمل في المتصفح وExcel يوفّق بين بيانات إيرادات Google Ads وGA4 وSearch Console وCRM لكشف أداء الاكتساب الفعلي، وتضخّم الإسناد الخفي، والإنفاق الإعلاني المهدور.**

**بدون تسجيل. بدون تثبيت. مجاني في متصفحك.**

## ما يساعدك على تتبعه

* التحويلات الإعلانية المبلّغة مقابل النتائج التجارية المؤكدة عبر CRM.
* تكلفة اكتساب العملاء الفعلية بعد إزالة العملاء المحتملين غير الصالحين وغير المؤهلين.
* الإيرادات المتولدة من الحملة بناءً على السجلات المالية بدلًا من ادعاءات المنصات الإعلانية.
* تسرّب الإسناد الخفي بين منصات التسويق والواقع التشغيلي.
* مصطلحات البحث التي تستهلك الميزانية دون توليد فرص مؤهلة.
* إجراءات التحسين الخمسة الأعلى تأثيرًا مرتبة حسب القيمة القابلة للاسترداد.

## لماذا بنيت هذا

بنيت هذا الإطار في الأصل بعد أن واجهت الفشل التحليلي نفسه مرارًا وتكرارًا في أعمال الخدمات المحلية والوكالات وفرق التسويق الصغيرة: كان الجميع يحسّن حملات التسويق باستخدام أرقام صحيحة تقنيًا لكنها خاطئة تشغيليًا.

قد تبدو الحملة ناجحة داخل Google Ads:

| المقياس      | تقرير المنصة |
| ----------- | --------------- |
| Spend       | $15,843         |
| Conversions | 480             |
| CPA         | $33             |

فيستنتج صاحب العمل:

> "تسويقنا يعمل."

لكن بعد تسوية تلك الحملات نفسها مقابل سجلات CRM والأعمال المكتملة، بدت النتيجة التجارية الفعلية مختلفة تمامًا:

| المقياس          | واقع مدقق عبر CRM |
| --------------- | ------------------- |
| Qualified Leads | 95                  |
| Completed Jobs  | 24                  |
| Real CPA        | $166                |
| Real ROAS       | 3.05×               |

لم تكن المشكلة في البرمجيات غير الدقيقة.

المشكلة كانت فشلًا تحليليًا: منصات التسويق تُحسّن للأحداث المسجّلة، بينما الأعمال تنجو بالمعاملات المكتملة والإيرادات المحصّلة.

هذا المشروع يُنتِج إطار استدلال قابلًا للتكرار:

1. ابدأ بالأداء التسويقي المعلَن.
2. تتبّع كل تحويل داخل الأنظمة التشغيلية.
3. أزل الأحداث غير المؤهلة والمكررة وغير التجارية.
4. أعد حساب اقتصاديات الاكتساب باستخدام واقع العمل.
5. رتّب التدخلات حسب الأثر المالي.

بدلًا من بناء لوحة أخرى، بنيت منهجية تدقيق قابلة لإعادة الاستخدام تجيب على سؤال أبسط:

> **"أي دولارات تسويقية أنتجت إيرادات فعلية؟"**

## لمن هذا

هذه الأداة مصممة لـ:

* أعمال الخدمات المحلية التي تُشغّل Google Ads.
* الوكالات الصغيرة والمتوسطة التي تُجري تدقيقات تسويقية.
* فرق عمليات التسويق التي تتحقق من جودة الإسناد.
* أصحاب الأعمال الذين يحاولون تسوية الإنفاق التسويقي مع الإيرادات الفعلية.
* المستشارين الذين يُجرون مراجعات كفاءة الاكتساب.

هذه الأداة غير مصممة لـ:

* منصات أتمتة التسويق للمؤسسات.
* أنظمة نمذجة الإسناد متعددة اللمسات.
* منصات بيانات العملاء (CDP).
* المؤسسات التي تتطلب تحليلات جارية في الوقت الفعلي.

**لا حاجة إلى خبرة في جداول البيانات. افتح النسخة المتصفح أو مصنف Excel وابدأ التدقيق فورًا.**

### ثلاثة فخاخ تصطاد حتى فرق التسويق ذوي الخبرة

#### الفخ #1 — تضخّم التحويلات على المنصة

**قرار اتُخذ:**

زد الميزانية لأن CPA تبدو منخفضة.

| المقياس      | المنصة | المدقق |
| ----------- | -------- | ------- |
| الإنفاق       | $15,843  | $15,843 |
| التحويلات | 480      | 95      |
| CPA         | $33      | $166    |

**لماذا يفشل هذا الاستدلال:**

تُحسّن المنصات الإعلانية للأحداث المسجّلة بدلًا من النتائج التجارية.

**النهج الصحيح:**

احسب اقتصاديات الاكتساب فقط بعد التسوية مع CRM.

**نتيجة القرار الصحيحة:**

قلّل تخصيص الميزانية وأعد تصميم تتبع التحويلات.

<details>
<summary>منطق الصيغة</summary>

```excel
=IFERROR((Reported_Conversions-Real_Leads)
/Reported_Conversions,0)
```

```excel
=IFERROR(Total_Spend/Matched_Real_Leads,0)
```

</details>

---

#### الفخ #2 — تحسين الكلمات المفتاحية عالية الحجم منخفضة الجودة

**قرار اتُخذ:**

زد العطاءات على مصطلحات البحث عالية الحجم.

| مصطلح البحث          | الإنفاق | العملاء المحتملون | القرار |
| -------------------- | ----- | ----- | -------- |
| emergency plumber    | $220  | 12    | إبقاء     |
| free plumbing advice | $310  | 0     | استبعاد  |

**لماذا يفشل هذا الاستدلال:**

حجم النقرات يقيس الانتباه، لا النية التجارية.

**النهج الصحيح:**

قيّم مصطلحات البحث باستخدام إنتاج العملاء المحتملين المؤهلين.

**نتيجة القرار الصحيحة:**

استبعد أنماط البحث غير التجارية.

<details>
<summary>منطق الصيغة</summary>

```excel
=IF(
 AND(
   Spend>(Max_CPA*1.5),
   Leads=0
 ),
 "CRITICAL WASTE",
 "KEEP"
)
```

</details>

---

#### الفخ #3 — تخصيص الميزانية بناءً على ROAS المبلّغ

**قرار اتُخذ:**

انقل الميزانية نحو الحملات التي تبدو ناجحة.

| الحملة   | ROAS المبلّغ | ROAS الحقيقي |
| ---------- | ------------- | --------- |
| Campaign A | 7.8×          | 1.4×      |
| Campaign B | 3.2×          | 4.5×      |

**لماذا يفشل هذا الاستدلال:**

ينكسر إسناد الإيرادات عند غياب التأكيد التشغيلي.

**النهج الصحيح:**

احسب ROAS من السجلات المالية.

**نتيجة القرار الصحيحة:**

أعد تخصيص الإنفاق نحو الحملات ذات إنتاج الإيرادات المتحقق منها.

<details>
<summary>منطق الصيغة</summary>

```excel
=IFERROR(
 Real_Revenue
 /
 Total_Spend,
0)
```

</details>

### سيناريو مثالي

تنفق شركة HVAC سكنية \$18,400 شهريًا على ثماني حملات Google Ads.

يُظهر التقرير الأولي:

| المقياس               | القيمة   |
| -------------------- | ------- |
| Ad Spend             | $18,400 |
| Reported Conversions | 562     |
| Reported CPA         | $32.74  |

بعد استيراد بيانات CRM:

| المقياس          | القيمة   |
| --------------- | ------- |
| Qualified Leads | 118     |
| Booked Jobs     | 31      |
| Revenue         | $57,200 |
| Real CPA        | $155.93 |
| Real ROAS       | 3.11×   |

يكشف التحليل الأعمق:

* 67% من التحويلات المبلّغة لم تدخل CRM أبدًا.
* ثلاث حملات ولّدت 72% من الإيرادات الفعلية.
* اثنتان وعشرون كلمة بحث استهلكت \$3,480 بصفر أعمال محجوزة.
* مجموعة كلمات مفتاحية واحدة لـ "free HVAC training" استهلكت \$940 وحدها.

الإجراءات الموصى بها:

1. أوقف حملتين ضعيفتي الأداء.
2. أضف ثماني عشرة كلمة رئيسية سلبية.
3. أعد تخصيص 35% من الميزانية نحو الحملات المتحقق منها.
4. استبدل تتبع التحويلات الأمامي بالتحقق عبر CRM.

وفورات سنوية متوقعة:

```
Recovered Waste:
$3,480/month × 12
=
$41,760/year
```

## أدوات أخرى من هذه السلسلة

* **محاكي تخصيص ميزانية Google Ads** — حسّن تخصيص الميزانية في ظل عدم اليقين.

المزيد من الأدوات متاح عبر مستودعات GitHub وحزم الإصدارات.
